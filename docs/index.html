Collega il tuo GitHub

Questa pagina salva le ricette dentro il tuo archivio su GitHub. Per farlo le serve il permesso, che si dà una volta sola con una chiave. La chiave resta in questo browser: non finisce online e nessun altro la vede.

  1. Apri la pagina delle chiavi su GitHub.
  2. Token name: scrivi Archivio Ricette.
  3. Expiration: scegli una scadenza lunga, o nessuna.
  4. Repository access: Only select repositories → scegli archivio-ricette.
  5. Permissions → Repository permissions → Contents → Read and write.
  6. Generate token, copia quello che compare e incollalo qui sotto.

Se un giorno vuoi revocarla, si cancella dalla stessa pagina di GitHub. Non serve mandarla a nessuno, nemmeno a me.
